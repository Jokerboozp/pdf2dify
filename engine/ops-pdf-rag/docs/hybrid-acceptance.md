# 本地混合检索验收（2026-09-21）

> 本页记录历史 #10。正式版本已迁移到 #11 Dify 原生检索，当前说明见 [原生检索运行与维护](native-dify-operation.md)。

本地 BM25、中文向量语义召回、RRF 合并和 BGE 重排已实现。2026-09-21 用户完成网络放行后，Dify 草稿联调通过并发布为 **#10**；正式演示入口的流程概览、项目撤销结转和原图放大均已实测成功。

## 数据与执行

- 257 份 PDF；4,840 个正文父章节、257 个流程导航条目；27,736 个检索窗口、512 维向量。
- 正文条目与当前导出清单完全一致；8,084 处正文图片引用与 160 处导航图片引用均存在。
- 首次索引后再次构建：新增计算 0，27,736 个向量全部复用。无变化时不创建重复快照。
- 44 项代码测试通过；依赖检查通过。首次模型下载后，向量与重排均在本机 CPU 执行。
- 本地 API 实测：项目撤销结转第一名为《财务模块常见问题.pdf》第 17 页，原图 HTTP 200、PNG 960×527。
- 本地 API 实测：上市范围返回 5 个章节，未上市范围返回 6 个章节，均严格位于所指定的原文编号前缀内。

## 同语料检索对比

固定的 22 题包括开发题、回归题及一条条件隔离题。初次测试发现 RRF 截断会丢掉只有语义命中的强候选；修复为两路各自前三名保留后复测。下表因此是**回归结果**，不是独立盲测。

| 模式 | 第一名命中 | 前五名命中 |
|---|---:|---:|
| BM25 | 15/22 | 17/22 |
| 仅向量 | 19/22 | 21/22 |
| 双路融合 | 17/22 | 21/22 |
| 双路融合＋重排 | 19/22 | 22/22 |

修复后另写 8 道未参与调试的题，通过实际本机 HTTP 服务运行；没有再根据这 8 题修改排名策略。

| 模式 | 第一名命中 | 前五名命中 |
|---|---:|---:|
| BM25 | 6/8 | 7/8 |
| 仅向量 | 8/8 | 8/8 |
| 双路融合 | 8/8 | 8/8 |
| 双路融合＋重排 | 7/8 | 7/8 |

**重排不保证每题更准。** 新题“系统不让我操作，说我这个用户的参数还没有配”对应问答在向量及融合模式排第一，重排后落到前五名之外。固定题中的“财务月结”在本地重排后总册排名也下降；Dify 保留原来的精确流程导航分支，实际预览仍正确返回 152 页总册的七个主要部分。

固定题和新题主要来自财务常见问题、跨模块问答及少量流程导航，覆盖有限。内部自定义简称、同名不同条件的流程和 OCR 异常仍需扩大业务验收，不能把这些命中率称为全库答案准确率。已保留 `--engine vector/fusion/hybrid/bm25` 对照入口；模型重排通常耗时数秒，较 BM25 或向量检索明显增加延迟。

## Dify 联调与发布 #10

最初 Dify Squid 返回 `503 / ERR_CONNECT_FAIL 110`，当时未发布草稿。用户随后告知网络已打开；本轮通过 Dify 页面重新验证，没有修改网络权限或扩大访问范围。

| 阶段 | 问题 | 实际结果 |
|---|---|---|
| 草稿 | 项目结转后怎么撤销？ | 工作流成功；CJ88、原结转变式/期间/年度、结算→冲销；《财务模块常见问题.pdf》第17页；原图点击放大成功 |
| 草稿 | 制造费用分摊，上市单位具体怎么操作？ | 限定条件分支成功；仅 1.1 的五个章节，第3–9页；显示3张配图 |
| 草稿 | 制造费用分摊，未上市单位具体怎么操作？ | 限定条件分支成功；仅 1.2 的配置和执行阶段，第10–38页；显示2张配图 |
| 发布 | 检查清单、发布更新 | 检查清单“所有问题均已解决”；发布面板显示“#10”“已发布” |
| 正式入口新会话 | 财务月结 | 152页总册的七个主要部分、页码范围及引导展开；返回流程概览成功 |
| 正式入口新会话 | 项目结转后怎么撤销？ | 返回图文答案成功；三步操作、第17页出处，原图实际放大可读 |

未上市草稿的运行追踪显示本地检索 1.660 秒，回答生成 40.046 秒。长章节回答会比简短问题慢。本轮验证确认功能可用及来源条件隔离，不代表全库业务内容均正确。

本轮未上市回答的第三处配图只显示说明文字，前两张正常呈现；未修改原文或推断第三张已显示。原手册中“执行分配循环”的正文事务码写为 KSU5，截图又出现 KSV5，回答沿用了正文；这是原文疑点，正式业务操作仍需复核，不能把演示通过当作事务码正确性认证。

演示入口：[ERP 运维知识助手](http://192.168.24.133:8811/installed/25089298-f80f-42e9-95c9-01c75de9c0d7)，需要登录现有工作区。原 #9 留在版本历史用于回退；本轮仅发布现有应用，没有启用匿名入口或创建新的 API 密钥。

本地服务当前以隐藏进程运行。Windows 重启后执行 `scripts/start-local-search.ps1`；原图签名链接一小时有效。配置与完整使用方式见 [本地混合检索说明](local-hybrid-search.md)。
